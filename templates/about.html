About TerraSense ML

Rockfall Early Warning and Response Coordination System for Decision Support.

PROJECT CONCEPT

Three complementary decision-support layers.

The application combines a supervised classifier for pattern-based risk estimation, a deterministic threshold engine for explicit sensor limit violations, and a protocol retrieval component that surfaces only verified site documentation.

Technical stack

  • Python / FlaskApplication and routing layer
  • Scikit-learnRandom Forest pipeline and evaluation
  • Pandas / NumPyTabular data handling
  • SQLiteZones, observations, alerts and protocols
  • JoblibSerialized fitted pipeline
  • Chart.jsDashboard and diagnostics visualization

Model workflow

  1. Load labelled sensor dataset
  2. Stratified train/test partition
  3. Median imputation and scaling in pipeline
  4. Stratified five-fold cross-validation
  5. Random Forest fitting and evaluation
  6. Class probability inference and persistence
Safety disclaimer: this is an academic research prototype, not a certified geotechnical monitoring or emergency alert product. Synthetic data and example thresholds are not suitable for real operational decisions.
